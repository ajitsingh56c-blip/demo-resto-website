# 🍽️ Ajit Restaurant

A modern, premium, and fully responsive **demo restaurant website** built for Ajit Restaurant.

The website provides a complete restaurant experience with interactive menus, food ordering, table reservations, animations, and a simulated payment checkout system.

## ✨ Features

* 🎬 Premium restaurant opening animation
* 🍛 Interactive food menu
* 🔍 Menu search and category filtering
* 🛒 Functional shopping cart
* ➕➖ Quantity controls
* 💰 Indian Rupee (₹ INR) pricing
* 🧾 GST and total price calculation
* 📦 Demo food ordering system
* 🪑 Table reservation system
* 💳 Dummy payment gateway
* 📱 UPI payment simulation
* 💳 Card payment simulation
* 🏦 Net banking simulation
* 👛 Wallet payment simulation
* 💵 Cash on Delivery option
* ✅ Payment success/failure simulation
* 📋 Order confirmation
* 🚚 Demo order tracking
* 🖼️ Interactive food gallery
* ⭐ Customer reviews carousel
* 📍 Restaurant location section
* 📞 Contact section
* 📱 Fully responsive design
* ✨ Smooth animations and transitions

## 💳 Payment Disclaimer

This website contains a **dummy/demo payment system** for testing and demonstration purposes.

> ⚠️ No real payments are processed.

Do not enter real card details, banking credentials, OTPs, or other sensitive financial information.

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/ajitsingh56c-blip/demo-resto-website.git
```

Open the project:

```bash
cd demo-resto-website
```

Install dependencies if required:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Then open the local URL provided by your development environment.
